🔹 Post, explore, and book accommodations  
🔹 Reviews, login/signup, secure routes, image uploads  
🔗 [GitHub Repo](https://github.com/GurkiratKaur3112/Wanderlust)

---

### 🧹 ServiceSphere – Service Marketplace *(In Progress)*  
A platform connecting underprivileged workers (maids, drivers, nannies, etc.) with service seekers.  
🔸 React + Node.js + Firebase  
🔸 Role-based listing & filters for customers  
🔸 Goal: Empower India’s unorganized workforce  
🔗 [GitHub Repo](https://github.com/GurkiratKaur3112/ServiceSphere)

🎨 Clean UI with floating navbar & Aceternity UI components
